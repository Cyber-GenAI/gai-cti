## Installation Prerequisites

### Server Requirements

- **Type:** Bare-metal server or virtual machine  
- **Minimum Specifications:**
  - CPU: **12 cores**
  - RAM: **45 GB or more**
  - Disk: **150 GB**
  - Public IP: *Optional but recommended*

### Optional Components

- **Domain Name:** A domain that resolves to the public IP  
- **CDN Account:** Access to a CDN provider (e.g., [ArvanCloud](https://www.arvancloud.ir))

### Project Source

- Project source code, available via:
  - **Git clone**, or  
  - **ZIP archive**

### Environment Setup

- **Internet:** High-speed connection  
- **Operating System:** Modern Linux distribution  
  - Recommended: **RHEL 9** or **Ubuntu 24.04**
- **Container Engine:** **Docker Engine v28** or newer  
- **API Keys:**
  - **Alianvalt API Key**
  - **AvalAI API Key**
